# Scams & Internet Fraud Archive

Un repositorio dedicado a la **documentación de los mensajes spam** en plataformas y redes sociales populares (Discord, Instagram, X/Twitter, etc.).

El objetivo principal de este proyecto es mostrar a todos los usuarios los tipos de mensajes spam que pueden recibir en diferentes plataformas y redes sociales.

---

## 📁 Estructura del Repositorio

El contenido está organizado por **plataforma** y por **tipo de mensajes spam**:

```text
scams-internet/
├── discord/
│   ├── type1/   # Cuentas comprometidas (spam masivo por DM, servidores, @everyone)
│   └── type2/   # Falsos reportes / Ingeniería social ("Te reporté por error")
├── instagram/
│   └── type1/   # Spam automatizado desde cuentas comprometidas (enlaces externos)
└── README.md
```

## 🤝 Cómo Colaborar

Las contribuciones son bien recibidas para mantener la base de datos actualizada y alertar a más usuarios. Puedes aportar de las siguientes maneras:

1. **Aportar Evidencias o Capturas de Pantalla:**
   Si has recibido un mensaje sospechoso o intento de estafa y conservas capturas de pantalla, puedes compartirlas abriendo un **Pull Request** o creando un **Issue**.
2. **Documentar Nuevos Vectores de Ataque:**
   Si conoces una nueva modalidad de estafa que no esté presente en la lista, puedes redactar un archivo `.md` siguiendo las plantillas de las secciones existentes.
