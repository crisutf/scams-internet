# Discord Spam - Tipo 1 (Cuenta Comprometida)

## Descripción General
Un bot o script malicioso toma el control de una cuenta de Discord comprometida y ejecuta acciones automatizadas para propagar el spam de forma masiva sin el consentimiento del usuario.

## Funcionamiento del Ataque

1. **Mensajes Privados (DM):** Envía spam masivo a todas las conversaciones privadas recientes.
2. **Servidores:** Publica mensajes en todos los canales con permisos de escritura de los servidores donde la cuenta está presente.
3. **Menciones y Adjuntos:** Etiqueta a todos los miembros usando `@everyone` e incluye imágenes promocionales del fraude.
4. **Evasión y Detección:** Una vez enviado el spam, el script silencia o pone en la lista de ignorados a las cuentas con las que interactuó para evitar que el dueño de la cuenta note la actividad sospechosa por notificaciones de respuesta.
