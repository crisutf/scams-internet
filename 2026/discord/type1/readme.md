# Discord SPAM - Tipo 1

## ¿Cómo funciona?

Un bot o script malicioso toma el control de una cuenta de Discord compromised y realiza las siguientes acciones de forma automatizada:

1. **Mensajes Privados (DM):** Envía spam masivo a todas las conversaciones privadas recientes.
2. **Servidores:** Publica mensajes en todos los canales con permisos de escritura de los servidores donde la cuenta está presente.
3. **Menciones y Adjuntos:** Etiqueta a todos los miembros usando `@everyone` e incluye las siguientes capturas/imágenes promocionales de forma masiva:
