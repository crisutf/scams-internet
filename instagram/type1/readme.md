# Instagram Spam - Tipo 1 (Cuenta Comprometida)

## Descripción General

Un bot o script malicioso toma el control de una cuenta de Instagram comprometida y ejecuta acciones automatizadas para difundir enlaces sospechosos e imágenes promocionales a múltiples usuarios sin la autorización del propietario.

## Funcionamiento del Ataque

1. **Mensajes Masivos:** La cuenta comprometida comienza a enviar mensajes privados (DM) de forma automatizada a sus seguidores y chats recientes.
2. **Difusión de Enlaces Maliciosos:** Los mensajes incluyen un enlace externo que redirige a sitios sospechosos de *phishing* o malware.
3. **Uso de Imágenes Promocionales:** Se adjunta una imagen diseñada para llamar la atención del usuario y motivarlo a hacer clic en el enlace adjunto.
4. **Publicación:** El bot sube un post en Instagram con la imagen y el enlace.
